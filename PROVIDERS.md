# True free LLM API providers worth signing up for

| Provider | Free Tier | API Key | Rate Limits | Privacy |
|----------|-----------|---------|-------------|---------|
| Groq | ✅ Generous | [console.groq.com/keys](https://console.groq.com/keys) | ~15-60 RPM | No training on paid tier |
| Google Gemini | ✅ Yes (unpaid quota) | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | ~15 RPM free | ⚠️ Free tier: prompts used for training |
| OpenRouter | ✅ Free models | [openrouter.ai/keys](https://openrouter.ai/keys) | Varies per model | Varies per model |
| Mistral AI | ✅ Free models | [console.mistral.ai](https://console.mistral.ai) | Limited free tier | Opt-out available |
| Cloudflare Workers AI | ✅ 10K neurons/day | [dash.cloudflare.com/ai](https://dash.cloudflare.com/to/ai) | 10K neurons/day | No training |
| SiliconFlow | ✅ Yes | [cloud.siliconflow.cn](https://cloud.siliconflow.cn/account/ak) | Limited | No training |
| Cerebras | ✅ Warp model | [cloud.cerebras.ai](https://cloud.cerebras.ai) | ~60 RPM | No training |
| Ollama | ✅ Local only (cloud API limited) | [cloud.ollama.com](https://cloud.ollama.com) | Limited | No training |

## Notes
- All above accept email-only signup (no credit card)
- All return JSON in OpenAI-compatible format (mostly)
- "Free tier trains your data" only applies to Google Gemini's Unpaid Services terms
- The Kimi K3 1M context promo through TokenRouter (Aug 2026) is expired and routes via a third-party
